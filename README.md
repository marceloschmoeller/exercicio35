# Exercício 35

## Descrição

O programa solicita ao usuário que digite 5 valores inteiros, armazena os valores em um vetor, calcula a soma dos números e a média aritmética dos valores informados.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Funcionamento

1. Solicita ao usuário 5 valores inteiros.
2. Armazena os valores em um vetor.
3. Calcula a soma dos valores.
4. Calcula a média aritmética.
5. Exibe a soma e a média na tela.

## Conceitos utilizados

- Vetores (arrays).
- Estrutura de repetição for.
- Variáveis do tipo int e double.
- Entrada de dados com Scanner.
- Operações aritméticas.
